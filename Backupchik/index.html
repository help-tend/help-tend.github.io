Backupchik — резервное копирование папок в облака

Программа для Windows, которая по расписанию копирует выбранные папки или целые диски компьютера в Google Диск, Яндекс.Диск и Облако Mail.Ru. Загружаются только новые и изменённые файлы, целостность каждого файла проверяется по контрольным суммам.

Несколько облаков и аккаунтов

Одну папку можно копировать сразу в несколько сервисов и в разные аккаунты одного сервиса.

Проверка целостности

MD5, SHA-1, SHA-256, SHA-384, SHA-512 и CRC-32 для каждого файла; сверка с хешами, которые вернуло облако.

Докачка после сбоя

При обрыве связи или отключении питания программа продолжает незавершённые загрузки после запуска.

Расписание и автоочистка

Ежедневно, еженедельно или ежемесячно; удаление старых копий из облака через 1–365 дней.

Служба Windows

Работает в фоне без входа пользователя в систему, управляется из окна и значка в трее.

Публичные ссылки

Можно поделиться загруженным файлом или папкой: ссылка копируется в буфер обмена прямо из программы.

Как Backupchik работает с Google Диском

Чтобы подключить Google Диск, пользователь нажимает «Войти»: открывается стандартная страница входа Google, где он вводит свой логин и пароль и разрешает доступ. Пароль от аккаунта Google программа не видит и не хранит.

Backupchik запрашивает только разрешение drive.file — доступ только к файлам и папкам, которые создала сама программа. Остальное содержимое Google Диска программе недоступно.

Все данные обрабатываются на компьютере пользователя: файлы передаются напрямую с компьютера в Google Диск. У программы нет собственных серверов, данные пользователей разработчику не передаются. Подробнее — в политике конфиденциальности.

Backupchik (English)

Backupchik is a free Windows desktop application that backs up selected local folders or entire drives to Google Drive, Yandex Disk and Mail.Ru Cloud on a schedule. Only new and changed files are uploaded, and the integrity of every file is verified with checksums (MD5, SHA-1, SHA-256, SHA-384, SHA-512, CRC-32). Interrupted uploads are resumed automatically. The app can run as a Windows service and lets users copy a public share link to an uploaded file.

Google Drive access. Users sign in on Google's own sign-in page; the app never sees the Google password. Backupchik requests only the https://www.googleapis.com/auth/drive.file scope, which gives access solely to files and folders created by the app. All processing happens locally on the user's computer; the app has no servers of its own and sends no user data to the developer.
