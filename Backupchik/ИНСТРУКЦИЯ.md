# Сайт Backupchik для Google Cloud — как опубликовать

В папке: `index.html` (главная), `privacy.html` (политика конфиденциальности),
`terms.html` (условия), `style.css`, `logo.png` (256×256), `logo-120.png` (120×120 — для Google).

Google требует, чтобы главная страница и политика конфиденциальности были открыты всем
и лежали на домене, который вы подтвердили в Google Search Console. Бесплатный вариант —
GitHub Pages: адрес будет вида `https://help-tend.github.io`.

Везде ниже `help-tend` — ваш логин на GitHub. Используйте ОДИН и тот же аккаунт Google для Search Console
и для Google Cloud.

## 1. Обновить сайт (GitHub Desktop)

Репозиторий `help-tend.github.io` уже создан. Новые файлы сайта уже скопированы в его папку
(`E:\GitHub\help-tend.github.io`, если вы создавали его там), осталось отправить их на GitHub:

1. Откройте GitHub Desktop, слева вверху выберите репозиторий `help-tend.github.io`.
2. Слева появятся изменённые файлы. Внизу в поле Summary напишите `Backupchik` → **Commit to main**.
3. Вверху нажмите **Push origin**.
4. Через 1–2 минуты откройте `https://help-tend.github.io` — должен открыться сайт Backupchik
   (если видите старый текст, обновите страницу с Ctrl+F5).

## 2. Подтвердить сайт в Google Search Console

1. <https://search.google.com/search-console> → «Добавить ресурс» → **«Ресурс с префиксом в URL»** →
   `https://help-tend.github.io/` → Продолжить.
2. Способ «HTML-тег» → скопируйте строку вида `<meta name="google-site-verification" content="...">`.
3. В `index.html` замените строку
   `<!-- GOOGLE_SITE_VERIFICATION: сюда вставьте мета-тег из Google Search Console -->`
   на скопированный тег. Загрузите изменённый `index.html` в репозиторий (Add file → Upload files).
4. Через минуту нажмите в Search Console «Подтвердить».

## 3. Заполнить экран согласия в Google Cloud

<https://console.cloud.google.com/> → ваш проект → «Google Auth Platform».

**Branding (Брендинг):**
- App name: `Backupchik`
- User support email: ваш e-mail
- App logo: **пока не загружайте** — с логотипом Google требует проверку бренда (несколько дней).
  Можно добавить позже: `logo-120.png`.
- Application home page: `https://help-tend.github.io/`
- Application privacy policy link: `https://help-tend.github.io/privacy.html`
- Application terms of service link: `https://help-tend.github.io/terms.html`
- Authorized domains: `help-tend.github.io`
- Developer contact information: ваш e-mail

**Data access (Доступ к данным):** «Add or remove scopes» → найдите и отметьте
`.../auth/drive.file` → Update → Save. Больше ничего не добавляйте.

**Audience (Аудитория):** User type — External → **Publish app** → Confirm.

**Clients (Клиенты):** «Create client» → Application type **Desktop app** → Name: Backupchik → Create.
Скопируйте **Client ID** и **Client secret**.

## 4. Вшить ключ в программу

Откройте `E:\Backupchik\backupchik\builtin_keys.py` и впишите:

```python
GOOGLE_CLIENT_ID = "....apps.googleusercontent.com"
GOOGLE_CLIENT_SECRET = "GOCSPX-..."
```

Запустите `build.bat`. Готово: Аккаунты → Подключить → Google Диск → браузер → логин и пароль Google →
«Разрешить».

Если Google при входе покажет «Приложение не проверено», нажмите «Дополнительные настройки →
Перейти на страницу Backupchik». Чтобы этого окна не было совсем, в Branding нажмите
«Verify branding» / «Подтвердить брендинг» — сайт для этого уже готов.
