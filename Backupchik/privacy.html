Политика конфиденциальности

Действует с 2 ноября 2026 г.

Эта политика описывает, какие данные обрабатывает программа Backupchik для Windows (далее — «программа») и как она использует данные, полученные от Google, Яндекса и Mail.Ru.

1. Кто обрабатывает данные

Программа работает только на компьютере пользователя. У неё нет собственных серверов, учётных записей и аналитики. Разработчик не получает, не собирает и не хранит данные пользователей.

2. Какие данные Google использует программа

  • Адрес электронной почты и имя аккаунта Google — чтобы показать пользователю, какой аккаунт подключён.
  • Файлы и папки на Google Диске, созданные программой (разрешение drive.file) — чтобы загружать резервные копии, проверять их контрольные суммы, удалять устаревшие копии по настройке автоочистки и создавать публичные ссылки по запросу пользователя.
  • Сведения об объёме хранилища — чтобы показать занятое и свободное место.

Программа не имеет доступа к другим файлам на Google Диске пользователя, к почте, контактам и другим сервисам Google. Пароль от аккаунта Google вводится только на странице Google и программе не передаётся.

3. Как хранятся данные

Ключи доступа (токены) хранятся только на компьютере пользователя в папке %ProgramData%\Backupchik и зашифрованы средствами Windows (DPAPI). Там же хранятся список файлов и их контрольные суммы. Содержимое файлов передаётся напрямую с компьютера в облачное хранилище пользователя по защищённому соединению (HTTPS).

4. Передача третьим лицам

Программа не продаёт, не передаёт и не раскрывает данные пользователей третьим лицам, не использует их для рекламы и не применяет их для обучения моделей искусственного интеллекта. Данные передаются только тому облачному сервису, который выбрал сам пользователь.

5. Соответствие требованиям Google

Использование и передача программой Backupchik любой информации, полученной от API Google, соответствует Политике Google в отношении пользовательских данных API-сервисов, включая требования об ограниченном использовании (Limited Use).

6. Как отозвать доступ и удалить данные

  • Отключить аккаунт в программе: «Аккаунты → Отключить».
  • Отозвать доступ программы к аккаунту Google: myaccount.google.com/permissions.
  • Удалить все локальные данные программы: удалить программу и папку %ProgramData%\Backupchik.
  • Резервные копии на Google Диске остаются в хранилище пользователя; их можно удалить через Google Диск.

7. Яндекс.Диск и Облако Mail.Ru

Для этих сервисов программа хранит логин и пароль приложения в зашифрованном виде на компьютере пользователя и использует их только для работы с хранилищем пользователя.

Privacy Policy

Effective November 2, 2026.

This policy explains what data the Backupchik desktop application for Windows ("the app") processes and how it uses data received from Google, Yandex and Mail.Ru.

1. Who processes data

The app runs entirely on the user's computer. It has no servers, user accounts or analytics of its own. The developer does not receive, collect or store any user data.

2. Google user data accessed

  • Google account email address and name — to show the user which account is connected.
  • Google Drive files and folders created by the app (drive.file scope) — to upload backups, verify their checksums, delete old backups according to the user's auto-cleanup setting, and create share links when the user requests one.
  • Storage quota information — to display used and free space.

The app cannot access any other files in the user's Google Drive, nor Gmail, Contacts or other Google services. The Google password is entered only on Google's sign-in page and is never available to the app.

3. Storage

Access tokens are stored only on the user's computer in %ProgramData%\Backupchik, encrypted with Windows DPAPI, together with the list of backed-up files and their checksums. File contents are transferred directly from the user's computer to the user's cloud storage over HTTPS.

4. Sharing

The app does not sell, transfer or disclose user data to third parties, does not use it for advertising, and does not use it to train AI/ML models. Data is sent only to the cloud service the user has chosen.

5. Google API Services User Data Policy

Backupchik's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. Revoking access and deleting data

  • Disconnect the account in the app: "Accounts → Disconnect".
  • Revoke the app's access to your Google account at myaccount.google.com/permissions.
  • Delete all local data by uninstalling the app and removing %ProgramData%\Backupchik.
  • Backups in Google Drive remain in the user's own storage and can be deleted in Google Drive.
